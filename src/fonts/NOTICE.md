## Previous registration font

Earlier previews used Zurich Extra Condensed (`ZurichBT-ExtraCondensed`), whose embedded notice identifies Bitstream Inc. and reserves all rights. No license granting font-file redistribution was found in this repository. The publisher offers commercial licenses: https://www.myfonts.com/collections/zurich-font-bitstream. Attribution alone does not grant redistribution rights. Zurich is not included in this font bundle; Bebas Neue is the default registration face, including New York.

A possible download source supplied by the maintainer is https://freefonts.co/fonts/zurich-extra-condensed-bold. That page lists Bold, while the previous repository asset identified itself as Regular, so the exact source is unconfirmed. The site's terms (https://freefonts.co/terms-and-conditions, checked 2026-09-12) defer to individual font terms and do not grant font-file redistribution rights. Its free-download description is not a redistribution license.
