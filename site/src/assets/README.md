# Preview serial font

`serial.otf` is a copy of `workshop/public/fonts/serial.otf`, the originating app's Zurich Extra Condensed Regular font. The docs use the same face as the workshop. Vite includes this asset in the site build with a base-aware URL; it is excluded from the npm package.

Its provenance is separate from Platekit's MIT source code license. Keep this copy consistent with the workshop asset when updating the preview font.
